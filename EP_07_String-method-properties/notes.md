# notes.md

String methods allow you to modify or inspect text values.

## Methods (Without Argument)

* **toUpperCase()** → converts to uppercase
* **toLowerCase()** → converts to lowercase
* **trim()** → removes spaces from both ends
* **trimStart()** → removes spaces from start
* **trimEnd()** → removes spaces from end

## Methods (With Argument)

* **includes(text)** → checks if text exists
* **indexOf(text)** → returns first position of text
* **replace(old, new)** → replaces first match
* **replaceAll(old, new)** → replaces all matches
* **concat(str)** → joins strings
* **padStart(len, pad)** → adds padding at start
* **padEnd(len, pad)** → adds padding at end
* **charAt(pos)** → returns character at position
* **charCodeAt(pos)** → returns ASCII/Unicode value
* **split(separator)** → converts string to array
