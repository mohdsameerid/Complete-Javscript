
# Watch Your Code Running Line by Line in DevTools

## WHAT

Using browser DevTools to debug allows you to pause code execution and see what happens **line by line**.

## HOW

* Open DevTools → Sources tab
* Add a **breakpoint** by clicking on the line number
* Refresh the page
* Use controls:

  * ▶️ Continue
  * ⏭ Step over
  * ⤵ Step into
  * ⤴ Step out
* Check variables in Scope panel

## WHY

* Helps understand code flow
* Quickly catch bugs
* See real-time variable changes
* Essential skill for professional debugging
