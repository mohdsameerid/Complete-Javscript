## Math in JavaScript

### Mathematical Operators

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division
* `%` Remainder
* `**` Power

Example:

```js
2 + 3
5 ** 2
10 % 3
```

---

## Math Object

Used for mathematical calculations.

### Properties

```js
Math.PI    // 3.141592...
Math.SQRT2 // Square root of 2
Math.E     // Euler number
```

### Methods

```js
Math.sqrt(16)    // 4
Math.pow(2, 3)   // 8
Math.floor(4.9)  // 4
Math.ceil(4.1)   // 5
Math.round(4.5)  // 5
Math.random()    // 0 to <1
```

### Infinity

```js
8 / 0   // Infinity
-8 / 0  // -Infinity
```

Division by zero returns Infinity, not an error.
