# Story of JavaScript — What, How, Why

---

## 1. What is JavaScript?
JavaScript is a high-level, dynamic, interpreted programming language primarily used to make web pages interactive.  
Created in 1995 by Brendan Eich at Netscape.

---

## 2. How JavaScript was Created (Timeline)
### 1995 — Birth of JavaScript
- Netscape wanted a scripting language for the browser.
- Brendan Eich created JavaScript in **10 days**.
- Originally named **Mocha**, then **LiveScript**, and finally **JavaScript** (for marketing).

### 1996 — Microsoft enters
- Microsoft releases **JScript** in Internet Explorer.
- JS code started breaking across browsers.

### 1997 — Standardization
- ECMA International created a standard named **ECMAScript**.
- ES1 → First official standard.

### 1999 — ES3
- The real backbone of JS.
- Added regex, better string handling, try-catch.

### 2009 — ES5
- Strict mode
- JSON support
- Array methods (map, filter, reduce)
- Big improvement in browser compatibility

### 2015 — ES6 (ECMAScript 2015)
The biggest update in JS history:
- let / const
- Arrow functions
- Classes
- Modules
- Promises
- Template literals
- Spread / Rest
- Default parameters
- Destructuring

### 2015 → Now — Yearly Releases
JavaScript now receives updates every year through TC39.

---

## 3. Why JavaScript became so popular?
### a) Runs in every browser
No installation, no compiler → huge adoption.

### b) Easy to learn
Simple syntax, friendly to beginners → massive community.

### c) Event-driven & asynchronous
Great for UI, network tasks.

### d) After 2009 — Node.js changed everything
JS moved from browser → server.

### e) Ecosystem explosion
React, Angular, Vue, Next.js, Express, Nest, etc.

### f) One language for entire stack
Frontend + Backend → JavaScript Full Stack.

---

## 4. Evolution of JavaScript Engines (Important)
### V8 Engine (Google)
- Launched in 2008 for Chrome.
- Compiles JS to machine code → **super fast**.
- The reason Node.js became possible.

### SpiderMonkey (Firefox)
First JS engine ever created.

### JavaScriptCore (Safari)
Apple’s engine.

### Chakra (Old Edge)
Microsoft’s engine before switching to Chromium.

---

## 5. JavaScript Today
- Used for web, mobile, backend, desktop apps, ML, AI, IoT.
- GitHub’s most popular language for many years.
- Powers frameworks like React, Next.js, Node.js.
