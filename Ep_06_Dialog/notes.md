# notes.md

Dialog boxes in JavaScript are built-in browser popups.

### Alert

Shows a simple message.

```js
alert("Hello!");
```

### Confirm

Asks user to confirm something. Returns **true** or **false**.

```js
const ok = confirm("Are you sure?");
```

### Prompt

Takes input from user. Returns text or **null**.

```js
const name = prompt("Enter name");
```

All three stop page execution until user responds.
