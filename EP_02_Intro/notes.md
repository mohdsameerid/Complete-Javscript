# Introduction to JavaScript (Optimized Notes)

- JavaScript is the language of the browser — it controls behavior, events, API calls, and UI logic.
- It is single-threaded, meaning it runs one line at a time on one call stack.
- BUT with browser features + event loop, it behaves asynchronously (timers, promises, fetch).
- JS runs everywhere now: browser, Node.js, mobile (React Native), desktop (Electron), servers.
- JavaScript follows ECMAScript standards — ES6 (2015) was the biggest upgrade.
- In browsers, JS interacts with three main things:
  - **DOM** (HTML elements)
  - **BOM** (browser features like history, alert, location)
  - **APIs** (fetch, events)
- JavaScript’s power comes from:
  - Closures
  - Prototypes
  - Async behavior
  - Dynamic typing
- You will write JS in three main ways:
  - In `<script>` tags
  - In separate `.js` files
  - As modules (modern, recommended)
- JS is everywhere because it is lightweight, fast, async, and supported by every browser.

# Important Interview Triggers
- “What makes JavaScript unique?” → Single-threaded + async behavior.
- “Does JS run only in the browser?” → No, Node.js runs JS on server.
- “Difference between JS and ECMAScript?” → ES is the standard, JS is implementation.
